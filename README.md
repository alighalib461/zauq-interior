## 🎨 Key Features & Specialties
- **Turnkey Residential & Commercial Solutions**: Complete interior design, false ceilings, and luxury fit-outs.
- **WPC & PVC Fluted Wall Panels**: Waterproof, termite-proof acoustic wall louvers and marble backdrops.
- **Laminated & Vinyl Flooring**: Premium German wood parquet, SPC click-lock, and luxury vinyl planks.
- **Window Blinds & Roman Shades**: Motorized and manual zebra, roller, and wooden Venetian blinds.
- **POP & Gypsum False Ceilings**: Ambient LED coves, spot lighting, and magnetic track systems.
- **Artificial Grass Turf**: High-density UV-stabilized synthetic grass for rooftops, balconies, and patios.
- **Interactive Cost Estimator**: Real-time project cost calculator with space type & area slider.
- **Direct WhatsApp Booking**: Seamless one-click WhatsApp inquiries for site surveys.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18+)

### Run Locally
```bash
# Clone the repository
git clone https://github.com/alighalib461/zauq-interior.git

# Navigate into directory
cd zauq-interior

# Start the local development server
npm start
```
Visit **`http://localhost:3000`** in your browser.
